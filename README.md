"# SmartAIChat" 


1 Phi-4 Mini + Ollama Integration — Local AI model integration for generating chat responses.
2 Python & Streamlit Integration — Built the chat application using Python and Streamlit.
3 Interactive Chat Interface — User-friendly SPA-style interface for real-time conversations.
4 Chat History — Maintains conversation context throughout the session.
5 Streaming Responses — Displays AI responses progressively for a real-time experience.
6 Custom System Prompts — Allows control over the AI assistant's behavior and instructions.
7 Connection Status — Shows whether the application is successfully connected to Ollama.
8 Clean & Responsive UI — Simple, modern, and user-friendly interface.
9 Local AI Processing — Uses Ollama to run the model locally rather than relying on an external AI API.
